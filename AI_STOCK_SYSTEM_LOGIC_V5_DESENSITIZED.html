⚡三大核心机制

整个系统由三条规则驱动，每一条都是硬约束，不可绕过。

01
市场评分 → 决定仓位上限
评分高位 → 高仓位
评分中位 → 中等仓位
评分低位 → 低仓位
评分极低 → 极低仓位

不论个股多好，市场不好就降仓位。
具体阈值参数为系统核心算法
02
综合评分 → 决定个股入选
机会评分（产业+资金+基本面+成长+技术+情绪+催化+估值）
减去风险扣分（财务+估值+破位+撤退）

最高评级才进核心组合，最低评级直接淘汰。
各维度权重参数为系统核心算法
03
资金四阶段 → 决定操作节奏
阶段1 资金进入 → 关注
阶段2 资金加速 → 建仓
阶段3 资金高潮 → 谨慎
阶段4 资金撤退 → 卖出

不追高潮，只在前两阶段布局。

🛡️仓位管理 — 市场评分驱动

仓位由市场评分决定，不是主观判断。评分高 → 仓位高，评分低 → 仓位低。这是硬规则。

市场评分市场状态建议仓位仓位示意
高位区间 强趋势牛市 高仓位
中高区间 结构性行情 中等仓位
中低区间 震荡 偏低仓位
低位区间 风险市场 极低仓位
各区间具体评分阈值与仓位比例为系统核心参数，不对外公开

🚨卖出规则 — 触发任意即执行

以下5条卖出纪律，触发任意一条即执行减仓/清仓。没有犹豫空间。

  • 1
    投资逻辑破坏 — 公司核心增长逻辑被证伪，催化因素消失
  • 2
    行业趋势下降 — 产业景气度拐头向下，政策转向不利
  • 3
    资金连续流出 — 主力净流出+北向撤离+ETF减持共振
    具体流出天数阈值为系统核心参数
  • 4
    评分显著下降 — 评级回落至低档，基本面或资金面恶化
    具体下降分值阈值为系统核心参数
  • 5
    跌破关键趋势 — 关键均线破位即减仓/清仓
    具体均线参数与减仓比例为系统核心参数

🔴风险委员会 — 每日必查

风险1：市场风险
大盘系统性下跌、流动性枯竭、外部冲击
风险2：行业集中风险
单一行业持仓过高，板块拥挤度过高
风险3：个股风险
财报暴雷、减持公告、诉讼/监管风险
风险4：情绪过热风险
涨停过多、连板过高、成交暴增、换手率异常
输出格式：风险等级（🔴红色 / 🟡黄色 / 🟢绿色） + 原因 + 建议（降仓位/止损/观望）
